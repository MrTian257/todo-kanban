# ADR-019：局域网共享（内嵌 HTTP 服务 + SSE 实时同步）

- 状态：已采纳
- 日期：2026-09（todo-kanban v2.x）

## 背景

桌面端是单机应用：数据在运行目录 `todo-kanban.db`，只能本机使用。需求是「把指定项目的待办面板通过局域网分享给其他设备」，
其他设备用浏览器打开即可查看并创建 / 分配任务，且任意设备的改动要实时同步给其它已连接设备（发起方自身除外）。

## 决策

1. **服务进程内嵌**：在 Tauri 壳 crate 内跑一个 axum HTTP 服务（`src-tauri/src/lan_server.rs`），绑定 `0.0.0.0:<port>`。
   不引入独立进程：局域网写入必须与应用共用同一把 `DB_RW_LOCK` 与同一条差异写链，跨进程会重新引入 MCP 那种跨进程并发问题。
2. **只共享勾选的项目**：共享配置（开关 / 端口 / 令牌 / 项目 id 列表）以 JSON 存 `app_meta`（键 `lan_share_settings`），
   不新增表、不动数据版本。筛选与合并逻辑放在 `core/src/svc/lan.rs`（纯函数 + 单测）。
3. **访客写入走同一条写链**：`db_cmds::lan_save_scoped` 在写锁内读取全量快照 → 共享范围内做快照比较（并发冲突即 `STATE_CONFLICT`）
   → 把访客的待办合并回全量 → 调用 `db::save_state_checked`。seq 取号、泳道校验、提交去重仍由原逻辑负责。
4. **对访客脱敏**：项目目录、仓库地址与 Token、待办的本地仓库路径不下发；比较两侧都走同一次脱敏，保证「原样读回再写」幂等。
   访客回写时，不可见字段（仓库路径 / 提交记录 / seq / 创建者 / 创建时间）一律以库内为准。
5. **实时同步用 SSE**：`/api/events` 长连接订阅广播。访客写入后立即广播；桌面端写入经 `notify_changed()` 立即唤醒；
   MCP 等外部写入由 `PRAGMA data_version` 400ms 轮询捕获。事件带 `origin`，发起方按客户端 id 跳过自己的回声。
   桌面端同时监听 Tauri 事件 `lan-state-changed`，收到即刻拉取，不依赖 2s 轮询。
6. **访客面板是单文件内嵌页面**（`src-tauri/src/lan_guest.html`，`include_str!`）：不经过前端打包，开发与发布行为一致，
   也不需要把访客 UI 打进 dist。

## 接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/` | 访客面板（单文件页面） |
| GET | `/api/state` | 共享范围快照 + 自定义字段定义 |
| POST | `/api/save` | `{ payload, expected, clientId }`；冲突返回 409 |
| GET | `/api/events` | SSE：`state`（含 origin）与 `resync` 事件 |

鉴权：查询串 `?t=<token>` / `X-Lan-Token` 头 / `Authorization: Bearer`；令牌为空表示局域网内免验证（设置页会给风险提示）。

## 取舍

- **访客不能改项目配置**：项目记录不采纳访客版本，只有待办可读写。避免共享配置 / 仓库凭据被远端改写。
- **共享范围冲突粒度**：桌面端修改未共享项目不会让访客保存失败；共享项目被并发修改时访客收到 409 并自动刷新重试。
- **端口固定可配**：默认 42800；绑定失败（端口占用）以设置页错误展示，不静默。
- **防火墙**：首次监听 `0.0.0.0` 时系统可能弹防火墙授权；设置页给出提示。

## 关于「任务分配」

- **泳道 / 状态分配（内置）**：访客可在卡片上拖拽或在下拉里切换泳道，即把任务分配到不同阶段。
- **分配给人（负责人）**：本应用原有模型没有「负责人」字段。需要时可在「设置 → 自定义字段」新建一个 `manual` 字段（如 text / select 的「负责人」），
  访客面板会自动下发该字段定义（`/api/state` 的 `fieldDefs`）并渲染成输入控件，可填写与修改；卡片上也会按 `showOnCard` 展示。**无需改数据版本即可完成「谁负责」的分配。**
- 若希望把它做成**一等字段**（卡片直接显示、可筛选、MCP 也可写、访客无需自定义字段配置），需要新增数据版本 v15（schema.rs / row.rs / db 三处 + 前后端类型同步）；可按需追加。

## 验证清单（人工）

1. `npm run build` + `cargo build`（或 `npm run tauri dev` / `npm run tauri build`）。
2. 项目资料页点某项目卡片上的「共享」；首次监听会弹系统防火墙授权，请允许**专用网络**。
3. 在另一台设备浏览器打开卡片 / 设置页给出的地址：`http://<IP>:<端口>/?t=<令牌>`（列表第一个通常是本机主网卡）。
4. 访客面板上新建 / 编辑 / 拖拽或下拉切换泳道（分配）/ 完成 / 删除任务。
5. 实时性：访客改动后桌面端应立即更新；桌面端改动后访客页应立即更新；**发起操作的那台设备自身不重复刷新**。
6. 冲突：两台设备同时改同一项目时，后保存的一方收到「数据刚被其他设备修改，已刷新为最新」提示，且不会覆盖对方改动。
7. 关闭共享：在项目卡片取消最后一个共享项目（或设置页关闭总开关）后服务停止，访客页显示连接已断开。
