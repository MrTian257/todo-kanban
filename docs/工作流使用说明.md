# 工作流使用说明

工作流（模板 / 提醒 / 备份 / AI 变更）从「设置 → 工作流 → 管理工作流」进入；
自定义字段与自动脚本从「设置 → 自定义字段 → 管理字段与自动脚本」进入（两者已从工作流拆分为独立设置项）。旧地址仍会自动跳转。

## 自定义字段

在「自定义字段」中新建字段，填写名称、类型、值来源和适用范围。可设置卡片展示，并使用列表中的上移、下移按钮调整顺序。

- **手动填写**：在任务中输入值，可以设置默认值和必填提示。
- **内置属性**：直接展示任务已有属性，类型随所选属性确定，不能由自动脚本改写这个引用字段。
- **自动脚本**：由规则填写，适合进入开发时间、自动分类等信息。

数字、日期、单选、多选等值按字段类型检查。修改已有字段的类型或选项不会自动删除历史值，需要按新定义检查原有任务。删除定义也会保留历史值；确定不再需要后，再使用「清理未定义字段值」。

## 自动脚本

这里的脚本通过「触发时机 → 条件 → 动作」配置。支持任务创建、进入泳道、状态变化、自定义字段变化和新增提交等触发时机；多个条件需要同时满足。

例如，自动记录进入开发的时间：

1. 新建「进入开发时间」字段，类型选择日期时间，值来源选择自动脚本。
2. 新建规则，触发时机选择进入泳道，再选择开发泳道。
3. 添加设置字段动作，目标选择「进入开发时间」，取值选择当前时间。
4. 保存并启用规则。以后任务进入该泳道并保存时会写入时间。

规则可以设置或清空自定义字段，以及开始时间、完成时间、计划日期、卡点等支持写入的内置属性。固定值和字段比较值会显示对应类型的输入控件。引用已删除的字段、泳道或项目时，界面提示失效，该规则不执行。

规则按列表顺序执行；字段变化可继续触发其他规则，每次保存最多处理三轮，每条规则对同一任务最多触发一次。规则不会追溯处理保存前的历史变化，也不支持定时触发或运行 JavaScript、Shell。

**存量任务补写**：规则只在事件发生的「那一刻」触发——在规则创建之前就已经处于目标泳道 / 状态的任务不会自动拿到值。这类任务用规则行上的「补写」按钮即可补齐：它把该规则的动作应用到当前已处于触发状态（泳道 / 状态）的任务上，只执行这一条规则、不级联其它规则，取值本来就相同的任务会跳过，改动可在任务变更历史中回滚。「任务创建时」「字段值变化时」「新增提交后」属于时点事件，无法确定补写范围，因此不提供补写。

## 保存与预览

配置保存会检查版本；其他窗口同时修改配置时，会提示冲突，避免覆盖其修改。

浏览器预览可体验字段和规则配置，配置保存在当前标签页的会话中；自动脚本需要桌面端，在任务保存时执行。恢复备份或历史记录不会执行自动脚本，以保留原始数据。
