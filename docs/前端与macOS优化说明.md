# 前端与 macOS 优化说明

本轮只修改源码和依赖锁文件，未运行测试、类型检查、构建或桌面应用；以下描述为代码实现范围，不能视为运行验收结果。

## 界面

- macOS 保留原生标题栏、红绿灯和菜单，应用内工具栏调整为 48px，增加当前页面标题，搜索框靠右。
- 侧栏增加工作空间分组，减小导航行间距，统一选中态；窗口失焦时弱化标题和导航选中颜色，正文保持正常对比度。
- 调整页面边距、任务行密度、面板和弹窗圆角及阴影，适配窄窗口。沿用现有明暗主题，不增加字体包。

## 可靠性与性能

- 尚未保存时取消 macOS 原生待处理退出请求；原生退出事件发送失败时取消退出，30 秒无人答复时取消本次系统退出，不强制结束进程。
- 完成待办、按时间补录、手动添加提交及检出分支后的任务写回，均比较请求前后的待办和项目快照；发生变化或删除时拒绝旧结果写回。Git 检出本身属于已执行的外部操作，拒绝写回不会撤销检出。
- 待办行、详情页和持久化状态组件改用字段订阅；待办行使用 memo，泳道数据按需计算。
- 虚拟列表按动画帧合并滚动和行高测量，二分定位首行，用 ID 索引定位保留交互的任务行，清理已移除任务的高度缓存。
- 保留原有规则：完成待办时若未指定分支，不自动查询或添加提交记录。

## 项目草稿

- 项目表单以 300ms 防抖写入本地草稿，支持恢复、丢弃及保留草稿并关闭。
- 草稿只包含表单业务字段和分支规则，不含 Token 或凭据引用。新输入的 Token 需重新填写。
- 草稿携带版本、保存时间、项目更新时间；超过 30 天的草稿在打开对应表单时清理，项目已变更的草稿不直接覆盖新数据。
- 保存项目成功后清理草稿；存储失败时显示错误。退出和导航前发出可取消的保存草稿事件，写入失败则保留编辑页面。

## 桌面启动与工具路径

- 主应用首先注册官方 single-instance 插件，重复启动时显示、还原并聚焦已有窗口。独立 MCP server 不注册此插件，可继续并存。
- Git / curl 支持 TODO_KANBAN_GIT_PATH / TODO_KANBAN_CURL_PATH 环境变量，值必须是可执行文件的绝对路径；显式配置无效时不静默改用其他程序。环境变量需由启动应用的进程继承，设置后重启应用和 MCP。
- 未显式配置时查找 PATH；macOS 查找失败后尝试 /opt/homebrew/bin、/usr/local/bin、/usr/bin，不执行 shell 初始化脚本。
- 设置页展示解析路径、来源与文件可执行性，不以路径存在代替版本或运行校验。
- TLS 继续使用系统默认校验，不添加证书开关或绕过参数。

实现参考：[Tauri 单实例插件](https://v2.tauri.app/plugin/single-instance/)。
