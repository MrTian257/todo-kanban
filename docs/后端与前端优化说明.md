# 后端与前端优化（仅代码实现，未测试）

## 提交与后台执行

- 项目/列表主动刷新按仓库分组，一次 API 分页查询匹配多条待办；每组最多 1000 条，最多并发 3 个仓库。
- HTTP 请求按完整 URL 和凭据隔离，合并重叠请求；服务端提供 ETag 时使用 If-None-Match/304，未提供时正常读取。缓存只驻留内存，最多约 128 个闲置分页槽，每个响应缓存上限 512 KiB。
- 主动刷新仍联系服务端，不按日期截断历史，以免漏掉晚推送的旧日期提交；这属于条件重验证，不是只查询最近 N 天。
- API 失败整组回退本地，界面显示回退原因；分页失败不返回部分记录。
- 本地来源分析缓存使用仓库 refs 快照、参考分支和 60 秒有效期；refs 变化后重算，最多保留 8 个仓库/分支分析。
- 所有现有桌面 Tauri 阻塞命令改为后台线程池执行，core/MCP 保留同步接口。
- 未指定分支的待办完成时不自动查询/新增提交；已有提交保留。手动刷新与手动补录仍允许空分支。

## 数据读取与界面

- 提交 API 配置只读 projects 的仓库相关字段，不再加载全量待办备注和提交。
- MCP 自定义数据目录在当前调用范围生效，不会从桌面默认数据库误取其他仓库配置。
- 外部同步持有同一 SQLite 只读连接比较 data_version；版本未变时不加载/传输完整状态。
- 读取前记录版本、事务内读取项目和待办，配合前端本地版本保护避免漏掉并发修改。观察连接重建或数据库文件更换时重新返回完整快照。
- 泳道列表一次遍历分组，再在各组内排序。

## 仓库 Token

| 系统 | 首选存储 | 不可用时 |
| --- | --- | --- |
| macOS | Keychain（apple-native） | 当前进程内存 |
| Windows | Credential Manager（windows-native） | 当前进程内存 |
| Linux | Secret Service（sync-secret-service，DBus 传输加密） | 无桌面服务、服务锁定或不可访问时仅当前进程内存 |
| 其他系统 | 不启用模拟钥匙串 | 当前进程内存 |

- 新保存的仓库 Token 不以明文写 SQLite；字段存 keyring://UUID 或 session://UUID。钥匙串服务名固定，凭据引用随机且不可变，桌面与 MCP 在相同用户和系统钥匙串可用时共享。
- 临时 Token 不写文件、不跨进程共享；重启、换设备或 MCP 单独启动时需重新输入。表单会显示临时状态，保存回退有提示。
- 钥匙串读取失败不把凭据置空；请求失败可回退本地 Git，用户可解锁系统钥匙串或在项目表单替换 Token。
- 每次替换创建新引用，避免数据库事务回滚时旧引用却指向被覆盖的密码。清除操作仅解除项目关联；旧系统凭据暂保留，避免破坏仍引用它的数据库备份。
- 旧版数据库的明文 Token 可继续读取，下次保存状态时迁移为引用；不主动修改现有数据文件或清理旧备份/WAL 中的历史数据。本次没有运行迁移。
- 本轮范围为仓库 API Token；MCP 自身访问授权 Token 的存储未调整。
- HTTP Token 通过标准输入管道传递，不出现在 curl 命令行参数中；错误信息不输出 Token。

## TLS 与字体

- 移除 curl -k，使用系统 curl 的默认 TLS 证书验证，不新增自签证书跳过或自定义 CA 配置；禁用 curlrc 以免继承 insecure 配置。
- 删除 IBM Plex Sans 依赖与入口。仅打包 IBM Plex Mono 的常用拉丁字符、400/500 字重；可使用机器已有的 JetBrains Mono、Cascadia Code、Consolas、Menlo。
- 正文中文字体使用 PingFang SC、Microsoft YaHei、Noto Sans CJK SC、WenQuanYi Micro Hei 的系统回退，不额外下载其他语言字体包。
- Markdown 普通内容、代码高亮、公式分开加载。公式输出 MathML，使用 WebView 的原生数学排版，取消 KaTeX 数学字体包。
- Vditor 离线同步脚本不复制第三方字体文件，并将本地 KaTeX 输出适配为 MathML。下次资源同步会清掉旧的生成目录后重新生成。

## 交付边界

按用户要求，仅编辑代码、依赖锁文件及说明，未运行测试、构建、lint 或桌面/浏览器验证。尤其需要后续在 Windows/macOS/Linux 核对钥匙串权限、Linux Secret Service、MathML 显示和跨进程同步。没有提交或推送代码。

参考接口：[keyring 3.6.3](https://docs.rs/keyring/3.6.3/keyring/)、[SQLite data_version](https://www.sqlite.org/pragma.html#pragma_data_version)。
