# Agent 本地任务记录约定

本仓库以本地 Markdown 记录需要跨会话跟踪的工程任务，不依赖 GitHub Issues 或其他外部问题跟踪器。

- 任务地图和任务条目写在 `.scratch/<effort>/` 下；`.scratch/` 为本机/会话用临时目录，不应作为产品文档入口。
- 任务条目使用清晰标题和可验证的完成条件；需要状态管理时以简洁文本记录状态、阻塞项和责任人。
- 发现的问题应尽量记录代码位置、影响、复现条件和证据。
- 长期有效的架构结论转入 `docs/` 或 ADR，不依赖临时任务票保存。
- 临时 tracker 完成后可随任务整理；不要在它们中放凭据或用户数据。
