# 项目资料库与全局项目上下文

## 目标

新增按项目管理的资料库，用于保存项目链接、Markdown 笔记和标签。左侧栏顶部展示并切换当前项目；切换后，项目看板、资料库和快捷新建待办使用该项目。今日焦点、全部待办和全局搜索继续跨项目工作。

## 数据模型与持久化

新增 `LibraryResource`：

- `id`
- `projectId`：可空；项目删除后设为 `null`，资料保留为未归属资料
- `title`：必填
- `url`：可选，仅允许 `http(s)`
- `note`：可选 Markdown 笔记
- `tags`：字符串数组，去除空白和重复项
- `createdAt`、`updatedAt`

`resources` 纳入前端 `AppState`、Rust `DbState` 和全量快照保存。SQLite 升级到 v9，新增 `resources` 表及 `project_id` 索引。保存时与 projects、todos 一样参与冲突比较、差异写入和删除差集处理。

项目删除时将关联资料的 `project_id` 置空；项目归档时资料保留但不在资料库中显示，恢复项目后重新可见。

MCP 的 `db_load_state` / `db_save_state` 同步资料数据；新增 `todo-kanban://resources` 资源，`todo-kanban://state` 同时包含资料库内容。工具数量保持 9 个。

## 当前项目上下文

`activeProjectId` 是本机界面偏好，保存至 localStorage，不写入 SQLite 或 MCP 快照。启动时恢复最后一次有效且未归档的项目；当项目被归档或删除时清除选择。

侧栏顶部由品牌区替换为项目上下文区：展开状态显示项目名称与目录或生产分支摘要，收起状态保留项目图标与切换入口。项目选择器仅列出活跃项目。选择项目后跳转至该项目看板。

项目卡片、看板和待办详情页会同步当前项目。资料库、项目看板与快捷新建待办使用当前项目；今日焦点、全部待办、全部待办中的项目筛选与顶部全局搜索不受限制。

## 资料库界面

新增 `/library` 路由和左侧“资料库”菜单。

- 没有当前项目时，显示选择项目提示。
- 有当前项目时，只展示该活跃项目的资料。
- 支持关键词搜索标题、链接、笔记和标签；支持按标签筛选。
- 支持创建、编辑和删除资料。
- 卡片显示标题、链接域名、标签、更新时间和 Markdown 笔记摘要。
- 编辑对话框提供标题、链接、标签和 Markdown 笔记；标题必填，链接可选且保存前校验协议。

## 验证

- Rust：v8→v9 迁移、资料读写、快照冲突、项目删除后资料未归属、归档项目资料隐藏。
- MCP：资料资源列表与读取、state 快照包含资料、保存资料不影响 AI 标记逻辑。
- 前端：标签归一化、当前项目恢复与失效清理、项目删除后的资料归属变化。
- 集成检查：`npm run build`、`cargo test -p todo-kanban-core`、`cargo test -p mcp-server`。

## 决策记录

资料数据属于共享业务状态，应随 SQLite 和 MCP 快照同步；当前项目是个人浏览偏好，因此只保存在本机。这样，AI 或其他窗口修改资料不会改变用户当前正在查看的项目。
