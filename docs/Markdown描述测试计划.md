## 1. 改动与验收范围

描述编辑从 contenteditable 富文本往返转换，改为受控 Markdown 源文输入。新增编辑、分栏、预览三种模式；预览与看板只读描述共用渲染器。表单使用当前 note 值，直接保存源文。

涉及文件：

- `src/components/todo/MarkdownEditor.tsx`：源文输入、工具栏、快捷键、图片插入、模式切换。
- `src/components/todo/MarkdownView.tsx`：CommonMark、GFM、公式、代码高亮、安全 HTML 与内嵌图片。
- `src/pages/TodoDetailPage.tsx`：描述与表单状态绑定。
- `src/index.css`：预览排版、表格滚动、主题和窄屏分栏。
- `package.json`、`package-lock.json`：新增渲染依赖。

支持目标为 CommonMark + GFM（表格、删除线、任务列表、自动链接、脚注），另加 KaTeX 数学公式与经清洗的 HTML。这里的“完整”不指所有私有 Markdown 方言：Mermaid 图形、MDX/JSX、任意 HTML/CSS/脚本、自定义容器等未实现；其源文应保留，不能宣称具备相应渲染能力。
