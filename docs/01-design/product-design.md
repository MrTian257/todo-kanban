# 产品能力

Todo Kanban 是围绕开发项目组织工作的桌面待办应用。当前页面和行为以 `src/App.tsx`、相应页面、store 与 core service 为准。

## 项目和待办

项目可关联代码目录与分支。待办在项目看板的泳道中管理，可保存日期、优先级、备注、自定义字段和提交关联。看板支持拖动排序；全部待办及今日焦点是跨项目视图。

## 项目资料库

资料库按当前项目展示链接和 Markdown 笔记，可检索、按标签筛选及增删改。资料可以不归属项目；删除项目会保留资料并解除归属。当前实现与字段见 `ResourceLibraryPage`、`ResourceEditorPage` 和 `LibraryResource`。

## 工作流与自动化

工作流支持任务模板、提醒、备份与 AI 变更提案等能力。设置中的自定义字段和自动化规则可根据任务事件写入支持的字段。细节见[工作流使用说明](../工作流使用说明.md)。

## Git 和报告

应用可读取本地 Git 信息，并查询 GitHub/GitLab 提交；待办可关联提交。日报、周报、月报根据项目仓库信息生成。当前 Git 平台能力以 `core/src/svc/forge.rs` 和 provider 实现为准。

## 番茄钟与 GrokBot

独立番茄计时器记录专注会话并提供统计；GrokBot 作为应用内宠物展示状态。可迁移渲染模块的接口见 `src/grokbot/README.md`。

## MCP 与局域网共享

MCP 为 AI 客户端提供工具和只读资源，可按 Token 配置写权限并记录审计。局域网共享允许访客面板查看或编辑管理员选定的共享数据。配置和安全边界分别见 MCP 指南及 ADR-019/023。

## 平台范围

桌面外壳使用 Tauri 2。浏览器开发预览只用于界面开发，使用演示数据，不提供完整桌面能力。发布平台与构建方式以 `src-tauri/tauri.conf.json`、GitHub workflow 和 `build.sh` 为准；发布操作不是开发预览。
