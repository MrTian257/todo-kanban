# 工作流使用说明

本指南介绍应用中工作流、模板、自定义字段与自动化的使用入口。当前菜单名称可能随界面调整，实际入口以设置页为准。

## 工作流与模板

打开「设置 → 工作流」管理项目泳道/状态相关工作流、任务模板及其配置。模板可作为新待办的初始内容。创建模板后，在新建待办流程中选择模板并按需调整生成的任务。

## 自定义字段

在「设置 → 自定义字段」创建字段，设置字段名称、类型、适用范围、输入来源及卡片展示选项。字段可供任务手动填写，也可引用内置属性或交由自动化规则维护。

修改字段类型或选项后，应检查已有任务值是否仍符合新定义。删除字段定义不会自动抹除历史任务中的字段值；使用页面提供的清理能力前，请确认不再需要这些值。

## 自动化规则

规则由触发时机、条件和动作组成。可用触发项和可写字段以当前页面表单及 `src-tauri/core/src/svc/automation.rs` 为准。规则通常在相关任务变更保存时执行；规则按配置顺序处理，同一保存周期有执行轮次和防重复限制。

使用建议：

1. 先建立需要写入的自定义字段。
2. 创建规则并选择触发时机和条件。
3. 添加字段或内置属性动作。
4. 检查规则引用的泳道、项目和字段是否仍存在，再启用规则。

规则不会自动解释任意 JavaScript 或 Shell。若页面提供“补写”操作，它用于将当前规则动作应用到已符合目标条件的存量任务；其范围和跳过条件以页面说明为准。

## 保存与浏览器预览

配置由桌面应用持久化并进行冲突检查。浏览器预览的数据保存在当前会话中，不是桌面 SQLite 数据；桌面专属自动化行为需在桌面环境验证。
