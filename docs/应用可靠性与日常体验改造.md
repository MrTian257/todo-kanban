# 应用可靠性与日常体验改造

状态：代码已修改，**本轮未执行构建、测试或桌面验收**。此前 Markdown 的 30 项通过记录不适用于本轮新增行为。

## 实现范围

### 数据与保存

- 数据加载区分无数据与读取异常。读取/版本检查失败展示错误入口，停止初始化写入，不把故障解释为空库。
- 本地数据变化才触发合并写队列；状态提示、初始化、外部同步不再回写数据库。
- 待办、项目、泳道、提交记录等成功提示等待保存完成。写入失败保留内存修改并展示重试；保存期间关闭窗口受到保护。
- 后端保存以 SQLite IMMEDIATE 事务获得跨进程写锁，在同一事务中比较修改前的 expected 快照。冲突抛出 STATE_CONFLICT，不写入旧快照。
- 返回保存后的规范数据，将后端生成的 seq/tag 回填到未继续修改的记录；不覆盖写入期间新增的本地编辑。
- 同步不重叠、可停止、重复启动会清理上一组监听；后台隐藏时暂停轮询。Git 预热串行执行且可取消。
- 数据冲突提供脱敏本地 JSON 导出与明确确认后的重新读取；不会自动用旧快照覆盖另一端数据。JSON 为保留副本，不是已经实现的自动导入恢复入口。

### 任务编辑与恢复

- 详情页面按项目/任务 ID 分别挂载，防止切换时表单沿用旧值。
- 无本地修改时同步最新任务；存在本地修改时提示冲突，由用户选择最新内容或明确保留自己的表单字段。
- 编辑草稿按任务保存到本机 localStorage，打开时提供恢复/丢弃；成功保存清除草稿。容量失败会提示，不宣称草稿已保存。
- 新任务/项目保存重试复用 ID，避免失败重试创建重复记录；创建分支成功后重试数据保存不重复创建同一分支。
- 删除延迟 8 秒执行，可在提示中撤销；撤销发生在真实删除前，因此附件元数据不会先被删除。等待期间记录变化会取消删除。不是永久回收站，8 秒之后不提供撤销。

### 日常体验与性能

- 顶栏全局搜索和非输入区域的 Cmd/Ctrl+K；搜索标题、描述、分支、标记、阻塞原因及项目名。
- 全部待办记忆搜索和筛选；提供结果数、清除筛选。全局搜索跳转到全部待办页。
- 全部待办使用可测量行高的虚拟列表，仅渲染可见区及缓冲区；项目看板的拖拽布局保持原实现。
- 页面模块和 Markdown 公式/高亮渲染模块改为按需加载，有加载反馈。
- 小于等于 700px 时自动收起侧栏；临时展开不覆盖桌面偏好。修正首次启动侧栏宽度缺省值。
- 为深色原生控件指定 color-scheme，明确工具按钮文字颜色。
- 全局显示保存/失败/冲突/同步失败，以及 Git 操作计数；提供重试入口。

## 保存 API 兼容性

UI 与 MCP 的 `db_save_state` 参数现在为：

```json
{
  "payload": { "projects": [], "todos": [] },
  "expected": { "projects": [], "todos": [] }
}
```

`expected` 必须是编辑前 `db_load_state` 返回的原始快照，`payload` 是基于它的修改。不能在冲突后拿最新 expected 配旧 payload 直接强制重试，否则会掩盖冲突。

旧 MCP 调用仅传 payload 将被拒绝。发布时 UI、Tauri 后端与 MCP 服务端须一起更新，并让客户端重新获取工具 schema。内部空库初始化保留不带 expected 的存储函数；外部写入入口必须走校验版本。

数据库 schema 未更改。本轮并发保护使用完整快照比较，数据量大时仍有序列化与传输开销，后续可改为数据库版本号和增量写入。
