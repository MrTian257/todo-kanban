自定义字段

在内置字段之外自定义属性：类型、候选项、默认值，以及值来源（手动填写 / 任务内置属性 / 自动脚本写入）。值随任务保存并参与变更历史与 MCP 读写。

完成时间日期时间任务内置属性doneAt所有项目
AI 协助标记勾选自动脚本写入所有项目
