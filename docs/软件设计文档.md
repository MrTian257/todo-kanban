# Todo Kanban 软件设计总览

本文是产品与系统当前实现的入口索引，不重复维护每个模块的字段清单。详细事实请查看源码及下列专题文档。

## 当前版本

- 产品版本：2.0.0（`package.json` 与 Cargo workspace）。
- SQLite 数据版本：16（`src-tauri/config/src/lib.rs` 与 `core/src/db/schema.rs`）。
- 前端：React 19、TypeScript、Vite、Zustand、React Router。
- 桌面与后端：Tauri 2、Rust workspace、SQLite。

## 产品功能

项目化待办、泳道看板、跨项目的今日焦点与全部待办、项目资料库、Markdown 块编辑器、Git 提交关联与报告、工作流/自定义字段/自动化、番茄钟与 GrokBot、MCP、局域网共享。

## 系统和数据

桌面 UI 通过 Tauri 命令调用 Rust core；MCP stdio 和应用内 HTTP 共用核心调度。共享业务数据存于 SQLite；当前项目及显示偏好是本机状态。数据库使用版本迁移，当前数据版本为 16。
